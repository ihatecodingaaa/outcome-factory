# Before every step, answer these five questions

1. Is the official BAND build window active? If no, is this action clearly research/tool readiness/generic design or explicitly approved prebuilt code? If not, WAIT.
2. What **published** judged requirement does this action serve? Link rubric ID; no 'looks impressive' extras without a user problem and specific grading fit.
3. Which threat model assertion or product value does this help prove? What actual evidence artifact will exist at demo time?
4. Does the action risk billed cloud spend, secret disclosure, cross-repo contamination, duplicate BAND identity, missing Git authorship, or license contamination? Require separate owner approval for any such action.
5. What is the rollback and runnable state? Record how we return to last green baseline within 15 minutes.

**Daily checkpoint:** show real runnable code and current red gates with exact commands, not generated slides. No fabricated metrics, customer testimonies or '100% confidence' claim.
